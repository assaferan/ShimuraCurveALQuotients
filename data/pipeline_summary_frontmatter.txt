WHAT THE ALGORITHM DOES
-----------------------
Goal: classify every Atkin-Lehner (AL) quotient X_0(D,N)/W of every Shimura
curve in range as SUB-HYPERELLIPTIC (geometric gonality <= 2, i.e. P^1, elliptic,
or hyperelliptic) or NOT.

Curves are never deleted from the working set; each is MARKED with a status:
  * open    -  IsSubhyp unassigned  (undetermined; could still be hyperelliptic)
  * ruled   -  IsSubhyp := false    (proven NOT sub-hyperelliptic)
  * proved  -  IsSubhyp := true     (positively classified P^1 / elliptic / hyperell.)

So "filtered out" at a step = how many curves newly became RULED OUT, and the
live candidate pool is the OPEN count. Filter* stages apply elimination criteria
(run in parallel); Update* stages are sequential bookkeeping that compute genera
and propagate each determination up and down the cover lattice.

The run proceeds in three phases:
  A. Star curves only      - the maximal AL quotient X* = X_0(D,N)/W* (one per (D,N)).
  Expansion                - each (D,N) is expanded into ALL 2^k AL quotients.
  B. All AL quotients       - per-curve filters on the full set.

NOTE on attribution: the per-step "newly-ruled" deltas above count when a curve's
OPEN status first changed in the pipeline ordering. The attribution census below
counts curves by the TEST whose proof is recorded on the curve (TestInWhichProved).
Every filter that records a verdict guards with "if assigned IsSubhyp then continue"
(don't overwrite), so TestInWhichProved holds the FIRST test that determined each
curve -- the census and the stage-table deltas agree where a tag corresponds to a
single step (e.g. FilterByALFixedPointsOnQuotient: 8098 newly-ruled = 8098
recorded; FilterByComplicatedALFixedPointsOnQuotient: 307 = 307; DualGraph: 425 +
658 = 1083). The two views still differ where a tag aggregates work across phases
or via lattice propagation rather than a single step: the "Trace" tag (1257)
collects both the Phase-A FilterByTraceStar (815) and the Phase-B FilterByTrace
(442) rulings, and the "HyperellipticALInvolution"/"GenusLt3"/closure tags are
assigned in UpdateByGenus/UpdateCurves and then propagated through the cover
lattice. Treat the stage table as the makespan ("when first determined") view and
the census as the first-writer "which test determined it" view.
