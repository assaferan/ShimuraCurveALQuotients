# THE JACOBIAN OF EVERY OPEN QUOTIENT, DECOMPOSED -- BY TWO INDEPENDENT METHODS
#
# Computed 2026-10-22.  All 34 rows agree between the two methods, and all 34 agree with the genus
# computed independently from the trace formula.
#
# WHICH CURVES THESE ARE.  The 34 quotients left open after the pipeline rerun of PR #117 and the
# 27 further arguments recorded in hyperelliptic/open-cases/ -- that is, the rows marked OPEN in
# nelson/nold_open61.txt.  Two rows are the two different W at D = 141, N = 2.
#
# METHOD 1, EXACT (oldform.m, oldform_all.m).  By Jacquet-Langlands the differentials on X_0^D(N)
# are the weight-two forms of level D*N that are new at every p | D, so they decompose over the
# newform orbits of EVERY level M with D | M | D*N, not only M = D*N.  An orbit of level M enters
# through the degeneracy maps, one copy per divisor of D*N/M.  For p not dividing M the two maps
# into level pM span a w_p-stable plane on which w_p swaps them, so w_p has trace zero there and
# eigenvalues +1 and -1, one each; hence the copies split into simultaneous w_p-eigenspaces indexed
# by a free sign eta_p for each prime p of N at which the orbit is old, each sign vector occurring
# once.  At p | M the sign is the orbit's own eps_p, and at p | D it is MINUS that -- the
# Jacquet-Langlands flip.  So the orbit contributes dim(f) times the number of sign vectors making
# every w_m with m in W act as +1, which is a linear system over F_2 with 0 or 2^nullity solutions.
# The total must equal the genus, and nothing in the computation is fitted to that number.
#
# METHOD 2, CHEAP AND OFFLINE (jacdecomp.m).  If J ~ prod A_i with A_i simple of dimension d_i then
# P_p = prod P_{p,i} with deg P_{p,i} = 2 d_i, and a single P_{p,i} can factor FURTHER at a special
# prime -- so the irreducible factorisation of P_p over Q is always a refinement of the true
# decomposition, never coarser.  The coarsest pattern over several primes is therefore the answer,
# and the number of primes realising it is the confidence.
#
# BOTH SCRIPTS RUN ON THIS BRANCH, which is the point of writing them this way.  oldform.m uses
# only GenusShimuraCurveQuotient and Magma's own modular symbols.  jacdecomp.m builds the zeta
# numerator itself from ComputePointsViaTrace -- the same construction as ZetaNumeratorViaTrace,
# which lives on the branch of PR #130 and is on neither main nor this one, so calling it would
# have left the script unrunnable here.  The inlined version was checked against the #130-based one
# and reproduces all 34 rows identically.  The two intrinsics it does use, in automorphisms.m and
# ShimuraQuotients.m, are byte-identical on main and on this branch, so the shared-path divergence
# noted below does not touch this computation.  When #130 lands, the construction can become a call.
#
# ⚠ Method 2 is EVIDENCE, not proof, wherever the coarsest pattern was realised at few primes: the
# three weakest rows were 2030_1 at 3/6 and 6_385 and 714_5 at 2/5.  Method 1 settles all three,
# and agrees.
#
